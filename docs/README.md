## 3. 更新纪律

- 机制结论先落 `mechanism.md`，术语与口径落 `glossary.md`；两者不互相抄。
- 未确认的机制不写成结论（标 `❓`），数值占位进 `stubs.md`。
- 数值占位替换后重录基线，并在 `glossary.md` 的决定记录写明影响面。
- 文档不放绝对路径；链接用仓内相对路径或引擎文档占位路径。
