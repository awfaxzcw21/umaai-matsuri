# 拉面杯（scen14）PT 机制对照：它有「PT 生 PT」，剧本15 没有（11-06 08:00）

表侧一手：`E:/HJM/_ref01/matsuri-ref-01/data/master.mdb`（node:sqlite 只读）。
发行件对照：`E:/HJM/Ramen_AI_0.21/gamedata/scenario_ramen.json`（明文，无源码）。
**本页只记录一条负结果**：剧本15 的 PT 缺口不能用「缺 PT 反馈表」解释。

## 1 拉面杯确实有一条按累计 PT 分档的加成表

`single_mode_14_check_point_pt_effect`（`effect_type=2` ＝ 訓練効果）：

| pt_min–pt_max | 300 档起逐档 | effect_value（訓練効果 %） |
|---|---|---|
| 0–249 | — | 0 |
| 250–499 | | 3 |
| 500–999 | | 5 |
| 1000–1499 | | 8 |
| 1500–1999 | | 10 |
| 2000–2499 | | 12 |
| 2500–2999 | | 14 |
| 3000–3499 | | 16 |
| 3500–3999 | | 18 |
| 4000–4999 | | **20** |

外加 `single_mode_14_region_effect_bonus`（按地区 × PT 区间给 `add_value` 0→10）。

⇒ **拉面杯里 PT 会反过来抬訓練効果**：一局攒到 4,000+ PT 时，每一手训练都多吃 +20%。
它的发行件数据把这张表原样带进 `scenario_ramen.json` 的 `ramen_pt_effect`
（`pt_min 0/250/500/1000/1500… → xunlian 0/3/5/8/10`），和表侧逐档一致。

**所以「拉面那个 AI 的 PT 有没有问题」这句问反了**：它不是 PT 算错，而是它那个剧本
**本来就有 PT 复利**，越攒越多。拿它的 PT 行为去推剧本15，会推出一个不存在的机制。

## 2 剧本15 没有这张表（负结果，写死）

scen15 的六张效果表里 `condition_type` 取值只有这些：

| 表 | condition_type 取值 | condition_value 范围 |
|---|---|---|
| `single_mode_15_act_effect` | 0, 1 | type1 恒 =5（＝gauge 满 5 豆，与 #40/外部评审同形） |
| `single_mode_15_advice_effect` | 0, 2, 3 | type2 = 0..45（含义未定，见下） |
| `single_mode_15_fusion_effect` | 0, 3 | type3 = 0 |
| `single_mode_15_finals_act_effect` | 0 | — |

⇒ **没有任何一档以累计 PT 为条件**。scen15 也没有 `*_check_point_pt_effect` / `*_region_effect_bonus` 这类表。

**结论**：引擎在剧本15 上 −1,443 PT（−17.1%）的缺口，**不能**记在「缺 PT→加成反馈」这条上。
候选清单少一条，这是本页唯一用途。

## 3 顺带钉住的另外两条

1. **拉面杯没有「在卡友情之外再乘一层彩圈」这种结构**：它的 scenario 数据里 PT 相关字段全是明表
   （`gain_pt_base [300,400,500]`／`gain_pt_delta [30,40,50]`／`ramen_success_pt [1500,3000,3500,5000]`），
   友情只走卡本身的 `youQing`。
   ⇒ 我方 `training_leg` 里那条 `friend_mult` 二次应用（`shining_boost: 0.25` 那条路径）
   **是我方发明，不是继承来的**——与 `docs/人头定价改判_闪彩超价_20261106.md` §9 的修复互相印证。
2. **拉面杯带真实 `deyilv`（得意率）数值**（`ramen_pt_effect` 里 50/55/60/63/65…），
   而我们引擎的得意率至今是占位（`docs/glossary.md` 与 #? 那条未决）。
   注意别照抄：scen14 的得意率是「按 PT 档抬的乘区」，而我们已经证过 scen15 的得意率是
   **落位概率**、不是乘数（`docs/` 得意率缺口那条）——两个剧本不同义。

**羁绊值或演目 Lv 的阈值**，但**没有证据**，本页不下结论。
