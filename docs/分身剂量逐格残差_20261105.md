## 0. 问题、判据、识别假设

#56 要判的**不是整局分**，是一个局部定价：报文 `home_info.command_info_array[cell].sub_command_partner_array`
标出来的那个「追加参与」的人头，在训练结算里到底吃几条腿。三档假设：

| 档 | 人头 | 该卡词条 | 该卡友情 | 与主树关系 |
|---|---|---|---|---|
| `heads_only` | ✓ | ✗ | ✗ | 上游 `count_training_persons` 的**注释**口径 |
| `card_effects` | ✓ | ✓ | ✗（归零） | **＝现行为**（非彩圈 ⇒ `youqing = 0`） |
| `card_effects_friendship` | ✓ | ✓ | ✓ | 分身视作该卡在该格彩圈 |

**判据**＝同板内**逐格残差双差分**（DiD）。残差取「面板自报 `stat_gains`（结算前预告）− 引擎
`train_preview`（同一条腿的预告）」：

```
DiD(轴) = mean(pkt − eng | 分身格) − mean(pkt − eng | 非分身格)
```

第二项把「引擎对**这块板**的整体训练偏差」这个共因减掉，剩下的就是分身那一格值多少。
哪一档把 DiD 压到 0 附近哪一档对真机。
**不引入任何新常数**（这是硬约束：不许为了把残差压平去调任何乘区），也**不碰报文锚点**
`train_stat_anchor`（那是引擎的输入，拿它当判据就是自证）。

**识别假设**：同一块板内，引擎的偏差在分身格与非分身格相同。这条由 **placebo** 定量——
把非分身格随机分成同样大小的两组，DiD 就是本方法能分辨的最小剂量；小于它的读数一律记「分辨不了」。

## 1. 输入与前置事实

报文 → 决策板 → 面板形状 state（`tools/packet_to_state.py`，复用面板 `live_reader.pick_state`，零重新实现）：

### ① 先钉死一条报文结构事实：分身不是额外人头

`out/clone_states/*.json` 全量清点：**508 个 `sub_partner_ids` 槽，508 个都已在同一格的 `partner_ids` 里**（独占的 0 个）。
这不是新发现，是 #47 那条 **0 反例**硬约束 `sub_command_partner_array ⊆ training_partner_array`（3,350 标记 / 729 板，
`docs/matsuri_memo_cn.md` 分身节）在本实验这 303 块板上的**再确认**——记在这里是因为整份裁决的前提就是它。
⇒ 「追加参与」是打在**既有 partner** 上的标记，不是往格上再加一个人。
所以「分身计人头」不是本实验的假设，而是报文的读法；本实验只测**卡腿那两条**（词条 / 友情）。
（`state.rs:243` 那条「只在 `dist` 已含该槽时登记」的守卫因此从未丢过数据——465 处没进样本纯粹因为它们落在稽古行。）

### ② 人头记账：两组同形，不污染 DiD

面板 `persons` 与引擎 `heads` 之差只可能是 0 或 +1（剧本 NPC 人头枠 101..=115：面板计、引擎不计——
就是 `docs/分身剂量与引擎缺口_20261104.md` §3 那条上游自相矛盾的落点）：

| 组 | n | `persons − heads` 均值 | 分布 |
|---|---|---|---|
| 分身格 | 28 | **+0.179** | `{0: 23, 1: 5}` |
| 非分身格 | 599 | **+0.232** | `{0: 460, 1: 139}` |

差 0.053 个人头 ⇒ 不构成 DiD 的混淆。（**留给后来人的坑**：第一版核账按 `commands[cell]` 的**列表位置**取行，
位置 ≠ 训练位，读数里冒出 `-3/-4` 的假差；改按 `train` 名匹配——与 `state.rs:174` 同一口径——后归零。
`state.rs` 从来不是按位置匹配的，所以**实验数据本身没被这个坑碰到**，只是我的自检脚本写错过。）

## 3. 裁决

1. **`card_effects` ＝ 现行为胜出，#56 不改代码。** Σ DiD `+1.12`，五轴里**四轴**的 CI 含 0 且点估计都在
   placebo 地板量级内（力量 +0.85 对地板 0.12 偏大但 CI `[−0.2,1.9]` 不显著；智力 +0.04 基本为 0）。
   守门用例断言了「`CloneDose::CardEffects` 档逐字段等于上游 `default_calc_training_buff`」⇒
   主树现有装配**本来就**按这一档结算。**没有常数要加，没有行为要改。**
2. **`heads_only` 否证**：Σ `+11.95`，速度／力量／根性／智力四轴 CI 全在 0 右（速度 `+4.81` 对地板 `0.28` ＝ 约 17 倍）。
   撤掉词条腿会**系统性欠账**。这同时否证「分身只当人头、不吃该卡任何词条」的读法。
3. **`card_effects_friendship` 否证**：Σ `−55.16`，五轴 CI 全在 0 左，比地板大 30 倍。
   把分身视作该格彩圈（给友情乘区）会**严重过冲**——友情是 `add()` 里的乘算项，一条腿就 56 点。
4. **方法本身有效**（不是「分辨不了」）：三档跨度 67 点 vs placebo 地板 ~2 点；
   两个自检都过（非分身格 611 个里三档 `eng` 不同的 **0** 个；分身格 35 个里 `heads_only↔friendship` 有差的 **35** 个）
   ⇒ 剂量确实只动分身格，且动满了。
5. **一处未解释、也不许动手的泄漏**：`card_effects` 档**速度轴** `+2.81`，CI `[1.2, 4.6]` 不含 0，是地板 10 倍，
   分层后仍 `+2.94`。两个候选都没证据，都不构成改代码的理由：
   (a) 泄漏集中在**速度卡**的得意轴（`+3.71/24`），而耐力卡的得意轴是 `−1.27/11` ⇒ 像卡种特异，不像通用剂量；
   (b) 引擎在速度腿上的非线性（人头数、`train_level_count`、1200 压缩）在两组间不完全同形 ⇒ 属于识别假设的破口。
   ⇒ 只读成「现行为在速度轴略欠」，**不**读成「还需要第四条腿」。判这条要先扩样（§5）。

## 4. 结论的范围（只到这里，不许外推）

- **只覆盖普通训练行**。465/508 的分身槽落在稽古行，本档没测——稽古行的面板自报是「普通训练预告 ＋ 该板自报演目加项」的**和**，
  要先拆开那条恒等式才能进同一个 DiD（见 #68）。
- **卡种覆盖只有 速度(24)／耐力(11)**。力/根/智的分身卡样本为 0 ⇒ **不能**排除「不同卡种的分身剂量不同」。
- **判据是「预告 vs 预告」**（面板自报 vs 引擎自报），与 #40 同口径：比整局门禁灵敏得多，
  但继承面板自身的取整与显示口径，不等于实结算。
- n＝35。CI 按板整块重抽；分层/不分层点估计差 < 0.3，聚层与构成的影响都可忽略。
- 本档**不是**门禁结论。三分量配对 CRN 该走的还是 `tools/crn_gate.py`；这里判的是一个局部机制的档位选择。
