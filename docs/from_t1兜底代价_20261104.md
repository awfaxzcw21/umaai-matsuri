CP1 两臂都 0/144 大成功，CP2（t47）兜底臂 **29.9%** vs 关兜底 **73.6%**（McNemar p=0.0000），
CP3（t67）**95.1%** vs **100%**（p=0.0156）。

⇒ 但**这还不构成「删掉兜底」的结论**，因为这一臂的发表会动力学本身就没对上真机（§5）。

## 4. 为什么这不等于「删兜底」

1. **CP1 两臂 0/144，而真机每场大成功率约 54%**（`docs/发表会档位一手_20261103.md`）。
   from-t1 臂在 t23 就结构性够不到 need 3 ⇒ 这一臂的**发表会动力学与真机不符**，
   兜底在一个错的前提上做决策。
2. **35.04 次/局的改写率本身就是症状**，不是参数问题：真机玩家不会让 45% 的手被规则改写。
   我们这条 `forced_target`（`crates/matsuri-cli/src/searcharm.rs`）的触发条件是引擎侧自定的，
   **没有一手报文证明真机的「兜底」长这样**；#44 才刚读到真机侧对应物是
   `auto_setting_info`（游戏里的「教えセット」＝玩家声明的演目配置），那是**声明**，不是**逐回合改落位的规则**。
3. 按机制真实性铁律：**「关兜底分高」不能给一个语义未证的规则判死刑**——
   如果真机确实在发表会前牺牲落位，那正确结论是「我们的兜底公式错了」，而不是「删掉它」。

所以本条只留下三条硬事实：兜底在本臂**不买到任何一档**、**净减三分量**、**会挤掉已够格的场**。
