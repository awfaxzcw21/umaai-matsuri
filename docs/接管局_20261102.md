## command_id → 五维（一手，报文预告 == 结算，逐位吻合）

`home_info.command_info_array[].params_inc_dec_info_array` **不是 null**（之前记错过一次）：
它就是客户端算好的预告增量，`target_type` 1..5 = スピ/スタ/パワ/根/賢，10 = 体力消费，30 = スキルPt。

| command_id | 训练位 | 报文里出现顺序 |
|---|---|---|
| 101 | スピード | 1 |
| 105 | スタミナ | 2 |
| 102 | パワー | 3 |
| 103 | 根性 | 4 |
| 106 | 賢さ | 5 |

`command_id` 不是 `100+属性序号`（104 不存在，105 才是耐力、106 才是智力），
但 `command_info_array` 的**数组顺序 = 界面从左到右顺序**，这条更可靠。

`training_partner_array` 混装两种 id：1..6 = 支援卡 position，1000+ = 演目担当 NPC chara_id
（master.mdb `single_mode_15_act_member`：1009=流鏑馬 1096=神旗 1024=納舞 1029=大曳 1128=飛駆）。

## 技能货架与购买流程（一手，实机买通 弧を描いて 全程）

接管停在 t12 本番（用户判定接管没用）。以下为本局实机量到的机制，与后续凹分直接相关。

**三步提交**（前两步都不扣点，只有第三步扣）：
行左绿 **＋** 加入购物车（价格框变「獲得済」）→ **決定**（变「スキル獲得確認」）→ 绿 **スキル獲得** 才真扣。
行主体 / 价格框 / 「進化条件達成」徽章 点了都是空操作（本局在这上面白烧了十几手）。
报文核对：买通前后 `skill_point` 618→529（−89），`skill_array` 新增 204812 弧を描いて。

**ヒントLv 用 − / ＋ 调**，Lv1/2/3/最大 = 10/20/30/40% OFF，按 (组, 稀有度) 标价，**买技能不吃提示**。

**下位 → 上位是两笔分开付，但进化免费**：买到基座后那行徽章翻成「進化可能」，点「進化」直升进化体、不再花点。
同组实测三对：弧を描いて 204812 (217) → 螺旋のエキスパート 204811 (508)；
実直な走り 204332 (217) → 継続は力なり 204331 (508)；さらなる高みへ 203122 (217) → 強者の証 203121 (508)。
进化表三张（master.mdb）：`skill_upgrade_speciality`（剧本 15 恰好 6 条）、`skill_upgrade_description`（636 条，卡专属）、
`skill_upgrade_succession_skill`（**只有 3 条**：901351→91101351 / 901411→91101411（本卡）/ 911091→92111091）。

**本局货架实量 grade/PT 汇率**（越大越该买）：弧を描いて 217/89 = **2.44**；巨歩 217/100 = 2.17；
会心の一歩 217/100 = 2.17；継続は力なり 508/240 = 2.12；超新星爆発 240/132 = 1.82；
