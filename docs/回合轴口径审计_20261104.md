- 一手自证（`out/_ura_window_report.txt` §0，三个锚点）：比赛回合 ⇔ 表侧 `single_mode_turn.race_entry_type`、

  ⇒ **报文 turn ＝ 面板 ＝ 表行号（1 基，1–78），引擎 ＝ 报文 − 1**。
- 全仓唯一的显式换算点：`crates/matsuri-cli/src/state.rs:270`（`panel_turn`）与 `:271`（`base.turn = turn − 1`）。

## 3. `no_event_turns` 复核（判「成立」，且这张表在骏大祭没有对应物）

**代码事实**（三跳都可点）：`crates/matsuri-core/src/game/traits.rs:132` 在抽随机事件桶之前做
`if data.consts.no_event_turns.contains(&self.turn) { return vec![] }`，而这个 `data` 来自
`umaai_core::Data::get()`（`traits.rs:124`）＝**基础库**，不是本剧本的 `scenario_matsuri.json`；
实际装载的表是 `data/constants.json` 的
`[0,24,30,34,36,37,38,39,48,50,54,58,60,61,62,63,71,72,73,74,75,76,77]`（**引擎 0 基**，⇒ 面板 1/25/31/35/37–40/49/51/55/59/61–64/72–78，23 个回合）。
这条表**与基础库同源**（我核的是 sha1＋逐元素两层，别说成「整个文件都一样」）：
本仓 `data/constants.json`、`jidianbeiAI0.22/rust/data/constants.json`、`umaai-matsuri-upstream/data/constants.json`
三个文件 **sha1 全等**（`e327cf13ae1a`，25,254 B）⇒ 逐字节相同；
`E:/HJM/Ramen_AI_0.21/gamedata/constants.json` 是**另一个文件**（`39edbc31e5ab`，25,161 B，其它字段有差），
但它的 `no_event_turns` 值**逐元素相同** ⇒ 「引擎全局/基础库那张表」这个归属成立。
⇒ 就是 memo §6（2026-10-30 用户拍板「**不复用引擎全局 `no_event_turns`**，剧本自持按年次 + 延长段」）**要求不要用的那张表**，
所以实现确实偏离文档（`docs/mechanism.md:502`、`docs/glossary.md:227`、`docs/matsuri_memo_cn.md:783` 同一条）。

**报文一手说这张表在骏大祭不成立**（`out/_camp_axis_pkt.json`，13 局 / 3,844 帧；口径＝`check_event` 帧上
`event_id < 215000` 的**非剧本事件**，按 `(run, turn)` 去重）：

```
每个面板回合的「非剧本事件」均值：抑制表内 1.96 ｜ 表外 1.93   ← 没有抑制形状
满局 78 回合的 8 局里，落在抑制表 23 个回合中的「有事件回合」= 18/18/19/18/20/20/20/21（均值 19.25）
⇒ 真机在 23 个「应被抑制」的回合里，平均有 19 个照常发事件
```
换轴再测一遍（把表当面板号、或再减 1）⇒ inside/outside 仍是 1.65/2.05 与 1.73/2.01，
**三种轴读法都看不到抑制台阶**，所以这条不是轴混用造成的假象。

**但别把它当成「缺口＝少发 19 个事件」的方向性结论**，两条限制写清楚：
1. 「有 `check_event` 帧」≠「一次属性事件手」——帧里也包含选项确认（如 `event 1011` 是赛后事件，`逐源台账_20261103.md:60`），
   单位与 #32 台账的「真机 9 手／引擎 38.57 手（>30 段）」不同口径，不可直接相减；
2. 引擎虽然关掉这 23 个回合，`>30 段`的事件手仍比真机多（38.57 vs 9）⇒ **事件生成率本身没有一手约束**，
   这正是台账 §3.5 那条「事件 +300 **口径差，不采信**」的根因。

**净结论**：`no_event_turns` 用错表＝**确定的实现偏离**（memo §6 有主、代码没做），
但它的符号与量级要等**骏大祭自己的事件日程 + 每回合触发率**定出来才能算 ⇒ 派新任务，不在本文改代码、
不写任何常数。在此之前，**事件腿在整局投影里是 ±300 PT / ±545 五维的未定项**，报 LG15 缺口时必须挂着。
